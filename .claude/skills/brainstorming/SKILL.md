# Brainstorming Skill

This Skill helps facilitate structured brainstorming sessions to generate creative ideas and solutions for various problems and challenges.

## When to use this Skill

Use this Skill when:
- Exploring multiple solutions to a problem
- Generating ideas for new features or improvements
- Need innovative approaches to challenges
- Want to overcome creative blocks
- Seeking diverse perspectives on a topic

## Instructions

### Step 1: Define the Problem or Goal

Clearly state what you want to brainstorm about:
- What specific problem are you trying to solve?
- What goal are you trying to achieve?
- What constraints or requirements exist?
- What would success look like?

### Step 2: Choose a Brainstorming Technique

Select an appropriate technique based on your needs:

1. **Free Association**: Generate ideas without judgment, building on each other
2. **SCAMPER**: Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, Reverse
3. **Reverse Brainstorming**: Think about how to cause the problem, then reverse solutions
4. **Mind Mapping**: Visual organization of ideas around a central concept
5. **Six Thinking Hats**: Approach from different perspectives (facts, emotions, creativity, etc.)
6. **RAPID**: Rapid ideation with time constraints

### Step 3: Generate Ideas

Following the chosen technique:
- Encourage quantity over quality initially
- Welcome wild and unconventional ideas
- Build on others' ideas (yes, and...)
- Defer judgment until later
- Record all ideas without filtering

### Step 4: Organize and Categorize

After idea generation:
- Group similar ideas together
- Identify themes and patterns
- Remove duplicates
- Flag ideas needing clarification

### Step 5: Evaluate and Select

Evaluate ideas based on:
- Feasibility and implementation effort
- Potential impact and value
- Alignment with goals and constraints
- Required resources and risks
- Select top ideas for further development

### Step 6: Develop Action Plan

For selected ideas:
- Outline next steps
- Identify required resources
- Set timelines and milestones
- Assign responsibilities if applicable
- Define success metrics

## Examples

### Example 1: Improving User Onboarding
**Problem**: New users struggle to understand how to use the application
**Technique**: SCAMPER
**Ideas**:
- Substitute: Replace text tutorial with interactive walkthrough
- Combine: Integrate onboarding with first-time use rewards
- Adapt: Apply game-like progression systems from mobile apps
- Modify: Simplify initial steps to core actions only
- Put to another use: Use onboarding to collect user preferences
- Eliminate: Remove unnecessary profile setup steps
- Reverse: Start with advanced features and unlock basics over time

### Example 2: Reducing Bot Latency
**Problem**: Trading bot has high latency affecting trade execution
**Technique**: Reverse Brainstorming
**Ideas** (how to increase latency):
- Add unnecessary API calls
- Use synchronous processing everywhere
- Load all data into memory at once
- Use inefficient algorithms
- Block main thread with heavy computations
**Reversed Solutions**:
- Cache frequently accessed data
- Implement asynchronous processing
- Load data lazily as needed
- Optimize algorithms and data structures
- Use background workers for intensive tasks

## Best Practices

- **Set time limits** for each phase to maintain energy and focus
- **Encourage participation** from all stakeholders
- **Build on ideas** rather than criticizing them initially
- **Change perspectives** by considering different user roles or stakeholder views
- **Take breaks** during long sessions to maintain creativity
- **Visualize ideas** using diagrams, sticky notes, or digital tools
- **Follow up** promptly after sessions to maintain momentum

## Advanced Usage

For complex problems, combine multiple techniques:
1. Start with free association to warm up
2. Use SCAMPER for divergent thinking
3. Apply Six Thinking Hats for multi-perspective analysis
4. Conclude with dot voting for democratic selection
